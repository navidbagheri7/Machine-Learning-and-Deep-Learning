## Publish from this directory

Suggested repository name: `learning-generalization-lab`.

Create an empty repository, then set its URL and publish the local history:

```bash
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
git push origin v1.2.0
```

Code and original documentation use MIT. Data and external models retain their
source terms in [references](references.md) and [photo credits](photo_attributions.md).
