# Original source inventory

`manifest.json` records original filenames, byte counts, detected formats and SHA-256
hashes. The unchanged original files are kept under `originals/` on the author's machine
and are excluded from Git. This preserves provenance without publishing assignment
handouts, personal course identifiers, untranslated outputs or third-party paper PDFs.

The runnable public implementation is in `src/learning_lab`; the English walkthroughs
are in `docs/` and `notebooks/`. See [the reconstruction map](../docs/08_source_audit.md).
